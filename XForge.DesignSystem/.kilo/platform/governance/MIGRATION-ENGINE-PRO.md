# Migration Engine Pro

## Objetivo

Atualizar ou migrar Engineers sem perda.

## Comandos

```text
/xforge-backup
/xforge-migrar-engineer
/xforge-validar-migracao
/xforge-restore
```

## Suporta

- XForge Engineer antigo;
- KiloCode custom;
- Cline;
- Claude Code;
- Cursor;
- Copilot custom;
- prompts e agents customizados;
- .xforge existente;
- .kilo existente.

## Regra

Nada em `.xforge` deve ser apagado.
Conflitos devem ir para revisão.
