# XForge Enterprise Intelligence Platform

## Objetivo

Transformar o XForge de um conjunto de agentes, comandos e documentos em uma plataforma de inteligência empresarial coordenada.

## Pilares

```text
.kilo/platform/
├── engineering/
├── product/
├── knowledge/
├── business/
├── governance/
├── intelligence/
└── orchestration/
```

## Regra

O usuário deve operar por intenções simples. A plataforma decide internamente quais experts, skills, workflows, gates e knowledge packs utilizar.

## Compatibilidade

- VS Code + KiloCode.
- `kilo.jsonc` preservado.
- `.kilo/commands` preservado.
- `.kilo/skills` preservado.
- `.kilo/rules` preservado.
- `.kilo/workflows` preservado.
- `.xforge` preserva memória, conhecimento, backlog, sprints, roadmap, relatórios e customizações.
