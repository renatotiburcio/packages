# Intent Router

## Objetivo

Reduzir a quantidade de comandos que o usuário precisa lembrar.

## Comandos públicos estratégicos

```text
/analisar
/criar
/melhorar
/testar
/documentar
/aprender
/migrar
/release
```

## Como funciona

```text
Intenção do usuário
→ Chief Architect
→ Intent Router
→ Platform Pillar
→ Experts
→ Skills
→ Workflows
→ Gates
→ Outputs
```

## Regra

Comandos antigos continuam existindo para retrocompatibilidade, mas o usuário deve preferir os comandos públicos estratégicos.
