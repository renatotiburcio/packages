# why-memory-analysis

## Objetivo

Registrar não apenas o que foi feito, mas por que foi feito.

## Deve capturar

- contexto;
- problema original;
- alternativas consideradas;
- decisão tomada;
- tradeoffs;
- impactos;
- motivo da rejeição de alternativas;
- quem aprovou;
- data;
- fontes.

## Saída

Atualizar `engineer/why-memory` e, quando aplicável, criar ADR.

## Exemplos

```
/why-memory-analysis
/why-memory-analysis com parametros especificos do projeto
```
