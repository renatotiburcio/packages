# system-evolution-analysis

## Objetivo

Analisar evolução contínua do ecossistema.

## Deve identificar

- módulos ultrapassados;
- débito técnico crescente;
- arquitetura degradando;
- baixa cobertura;
- workflows inúteis;
- prompts não usados;
- skills obsoletas.

## Saída

- roadmap evolutivo;
- plano de modernização;
- plano de remoção;
- oportunidades enterprise.

## Exemplos

```
/system-evolution-analysis
/system-evolution-analysis com parametros especificos do projeto
```
