# /melhorar

## Objetivo

Melhora código, arquitetura, UX, performance, segurança, testes, documentação e usabilidade.

## Regra REV45

Este é um comando público estratégico. O Engineer deve interpretar a intenção, recuperar memória, consultar registries, selecionar pilares, experts, skills e workflows automaticamente.

## Saídas esperadas

- entendimento da intenção;
- plano;
- experts selecionados;
- execução;
- quality/security/UX gates;
- Enterprise Score quando aplicável;
- backlog/sprint/roadmap quando houver gaps;
- documentação e memória atualizadas.

## Exemplos

```
/melhorar
/melhorar com parametros especificos do projeto
```
