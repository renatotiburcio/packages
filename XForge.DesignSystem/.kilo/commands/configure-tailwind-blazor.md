# /configurar-tailwind-blazor

## Deve fazer

1. Detectar tipo do projeto Blazor.
2. Instalar:
   - tailwindcss
   - @tailwindcss/cli
3. Criar:
   - input.css
   - output.css
   - themes
   - tokens
4. Configurar watch/build.
5. Atualizar docs.

## Exemplos

```
/configurar-tailwind-blazor
/configurar-tailwind-blazor ambiente de desenvolvimento
```
