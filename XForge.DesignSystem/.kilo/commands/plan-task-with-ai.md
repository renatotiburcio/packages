# /planejar-tarefa-com-ia

## Objetivo

Planejar qualquer tarefa antes de executar.

## Deve entregar

- classificação da tarefa;
- comando recomendado;
- prompts;
- provider;
- thinking mode;
- riscos;
- arquivos afetados;
- checklist;
- critérios de aceite.

## Exemplos

```
/planejar-tarefa-com-ia
/planejar-tarefa-com-ia com parametros especificos do projeto
```
