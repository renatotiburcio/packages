# /analisar-projeto

## Objetivo
Analisar projeto existente ou novo para entender contexto, stack, arquitetura e riscos.

## Roteamento interno
- /reconhecer-projeto — analise de projeto existente
- /development-recognize-project — reconhecimento de padroes

## Uso
/analisar-projeto
/analisar-projeto --stack dotnet
/analisar-projeto --contexto erp-fiscal
