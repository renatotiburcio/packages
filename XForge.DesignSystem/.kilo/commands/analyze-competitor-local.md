# /analisar-concorrente-local

## Objetivo

Analisar concorrente ou referência usando apenas material local.

## Entradas possíveis

- PDFs
- Word
- Excel
- imagens
- prints
- ZIPs
- repositórios
- documentação interna
- anotações
- memória do Engineer

## Saída obrigatória

- resumo do concorrente;
- módulos identificados;
- telas identificadas;
- recursos identificados;
- pontos fortes;
- pontos fracos;
- oportunidades;
- matriz de features;
- proposta de produto superior;
- backlog inicial.

## Exemplos

```
/analisar-concorrente-local
/analisar-concorrente-local do projeto atual
```
