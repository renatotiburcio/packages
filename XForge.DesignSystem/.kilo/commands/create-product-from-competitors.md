# /criar-produto-a-partir-de-concorrentes

## Objetivo

Criar um novo produto usando análise competitiva profunda.

## Perguntas interativas

- Qual mercado/produto?
- Quais concorrentes?
- Usar web, local ou ambos?
- O objetivo é copiar, superar, simplificar ou reinventar?
- Público-alvo?
- MVP desejado?
- Restrições técnicas?
- Stack desejada?

## Saída obrigatória

- visão do produto;
- proposta de valor;
- módulos;
- features;
- UX strategy;
- arquitetura;
- MVP;
- roadmap;
- backlog;
- riscos;
- estratégia de diferenciação.

## Exemplos

```
/criar-produto-a-partir-de-concorrentes
/criar-produto-a-partir-de-concorrentes para o modulo de pagamentos
```
