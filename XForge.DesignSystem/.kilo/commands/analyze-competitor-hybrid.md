# /analisar-concorrente-hibrido

## Objetivo

Combinar conhecimento local, documentos, código, prints e fontes online para criar um produto novo ou superior.

## Fluxo

1. Estudar fontes locais.
2. Estudar fontes web.
3. Deduplicar informações.
4. Calcular trust score.
5. Criar matriz de features.
6. Criar mapa de módulos.
7. Criar mapa de telas.
8. Identificar gaps.
9. Propor diferenciais.
10. Criar MVP.
11. Criar roadmap.
12. Criar backlog.
13. Atualizar memória.

## Exemplos

```
/analisar-concorrente-hibrido
/analisar-concorrente-hibrido do projeto atual
```
