# /analisar-concorrente-web

## Objetivo

Analisar concorrente usando fontes públicas online.

## Regras

1. Priorizar fontes oficiais.
2. Registrar URLs estudadas.
3. Criar arquivo em `engineer/knowledge/studied/web`.
4. Separar fato de inferência.
5. Atualizar memória.
6. Gerar matriz de features.

## Saída obrigatória

- fontes consultadas;
- resumo;
- feature matrix;
- gaps;
- oportunidades;
- diferenciais recomendados;
- roadmap de produto.

## Exemplos

```
/analisar-concorrente-web
/analisar-concorrente-web do projeto atual
```
