# ecosystem-consolidation

## Objective

Analyze many existing systems and transform them into a unified XForge ecosystem.

## Inputs

- legacy apps;
- frameworks;
- libraries;
- components;
- documents;
- agents;
- skills;
- prompts;
- rules;
- specs;
- workflows;
- memory.

## Procedure

1. Inventory everything.
2. Classify by business capability.
3. Detect duplicated features.
4. Detect reusable assets.
5. Detect obsolete assets.
6. Map domains.
7. Map data entities.
8. Map integrations.
9. Create target architecture.
10. Create consolidation roadmap.
11. Create backlog.
12. Update memory and knowledge graph.

## Rule

Never copy legacy code blindly. Always analyze, normalize, refactor and validate.
