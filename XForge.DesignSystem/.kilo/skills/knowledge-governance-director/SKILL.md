# knowledge-governance-director

## Objetivo

Garantir qualidade, confiança e conformidade do conhecimento.

## Pólos de Governança

| Pólo | Critério | Ação |
|------|----------|------|
| **Qualidade** | Precisão, completude, atualidade | Validação periódica |
| **Confiança** | Fonte, corroboracão, idade | Trust score |
| **Acesso** | RBAC, dados sensíveis | Controle de acesso |
| **Lifecycle** | Criação → uso → obsolescência | Poda e arquivamento |
| **Compliance** | LGPD, auditoria, rastreabilidade | Logs e revisões |

## Métricas

| Métrica | Target |
|---------|--------|
| Knowledge freshness | < 30 dias avg |
| Trust score avg | > 70 |
| Coverage | > 80% de gaps preenchidos |
| Compliance | 100% em dados sensíveis |

## Procedimento

1. Auditar qualidade do knowledge
2. Verificar trust scores
3. Identificar gaps
4. Aplicar lifecycle rules
5. Gerar relatório de governança
6. Ações corretivas

## Regras

- Revisão trimestral obrigatória
- Dados sensíveis sempre protegidos
- Conhecimento obsoleto → deprecated
- Auditoria completa anual
