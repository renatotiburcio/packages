# expert-evolution-architect

## Objetivo

Projetar trilhas de evolução para especialistas e equipes.

## Níveis de Expertise

| Nível | Descrição | Responsabilidades |
|:-----:|-----------|-------------------|
| **Junior** | Aprende com supervisão | Implementar features guiado |
| **Pleno** | Trabalha independentemente | Definir e implementar soluções |
| **Senior** | Mentor, referencia técnica | Arquitetura, mentoria, reviews |
| **Staff** | Multiplica impacto | Padrões, processos, cross-team |
| **Principal** | Visão estratégica | Direção técnica, inovação |

## Trilhas

### Técnica
1. Dominar linguagem e framework
2. Entender arquitetura
3. Escrever testes eficazes
4. Mentorar outros
5. Definir padrões

### Leadership
1. Code review excelente
2. Comunicação clara
3. Gestão de projetos
4. Tomada de decisão
5. Influência sem autoridade

## Procedimento

1. Avaliar nível atual
2. Identificar gaps
3. Definir objetivos
4. Criar plano de desenvolvimento
5. Acompanhar progresso
6. Revisar trimestralmente

## Regras

- Growth deve ser mensurável
- Feedback contínuo
- Desafios progressivos
- Documentar conquistas
