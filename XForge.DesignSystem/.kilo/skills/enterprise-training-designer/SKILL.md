# enterprise-training-designer

## Objetivo

Criar e manter programas de treinamento para equipes.

## Estrutura de Trilha

### Onboarding (Semana 1-2)
1. Visão geral do projeto
2. Setup do ambiente
3. Arquitetura e padrões
4. Primeira feature (guided)
5. Code review com mentor

### Profundização (Mês 1-3)
1. Domínio de negócio
2. Padrões avançados
3. Testes e quality gates
4. Deploy e operações
5. Incidentes e suporte

### Especialização (Mês 3+)
1. Arquitetura
2. Segurança
3. Performance
4. Mentoria de novos

## Formatos

| Formato | Quando |
|---------|--------|
| Hands-on workshop | Setup, primeiros passos |
| Documentação | Referência contínua |
| Pair programming | Aprendizado prático |
| Lunch & learn | Tópicos avançados |
| Code review | Feedback contínuo |

## Procedimento

1. Identificar gaps de conhecimento
2. Definir objetivos de aprendizado
3. Criar trilha estruturada
4. Produzir materiais
5. Executar treinamento
6. Avaliar e ajustar

## Regras

- Treinamento deve ser prático
- Documentação sempre atualizada
- Feedback contínuo
- Medir efetividade
