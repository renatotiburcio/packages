# T078: XF SvgIcon IconCatalog refactor (variant+size+keyword) + SVG Comment Strip

## Objetivo
Substituir o flat Dictionary<string,string> (3698 icones) por uma estrutura com variant (Regular/Filled/Light/Color) + size (10/12/16/20/24/28/32/48) + keywords (search-friendly). **Durante o refactor, REMOVER todos os comentarios SVG (`<!--...-->`) para evitar vazao de metadata Font Awesome Pro (license comercial) no bundle MIT do XForge.**

## Passos
1. Criar enum XFIconVariant { Regular, Filled, Light, Color }
2. Criar enum XFIconSize { Size10, Size12, Size16, Size20, Size24, Size28, Size32, Size48, Custom }
3. Criar record XFIconInfo { Name, Variant, Size, Keywords[], Category, Content }
4. Refatorar XFSvgIcons.cs: agrupar icones Font Awesome por variant+size
5. Adicionar keywords (mapping FA name → keywords: e.g. "house" → ["home","building","main"])
6. **STRIP SVG COMMENTS** (CRITICO — license hygiene):
   - Regex: `<!--.*?-->` (multi-line, non-greedy, Singleline)
   - Remover TODO comentario HTML/XML do Content
   - PRESERVAR `<title>`/`<desc>` como elementos proprios (W3C SVG a11y)
   - **NAO pode vazar**: `Font Awesome`, `@fontawesome`, `Fonticons`, `Commercial License`, `Copyright 2025`, URLs fontawesome.com
   - Implementar em helper `SvgContentSanitizer.Sanitize(string svg): string`
7. Criar XFIconCatalog static partial class com API de lookup (sem reflection)
8. Migrar 3698 icones FA + 1 custom (agro-business) — todos sanitize
9. Manter backward-compat com XFSvgIcons.cs (delegar para novo catalog)
