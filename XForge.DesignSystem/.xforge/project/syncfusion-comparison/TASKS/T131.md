# T131: XFSankeyDiagram flow diagram

## Objetivo
Implementar diagrama Sankey para visualizacao de fluxos (caixa, cadeia de suprimentos, energia, etc). Syncfusion unico entre 8 fontes com Sankey nativo.

## Passos
1. Criar `src/XForge.DesignSystem/Components/Diagrams/Sankey/`
2. Model `XFSankeyNode` (id, name, color)
3. Model `XFSankeyLink` (source, target, value, color)
4. Layout algorithm (d3-sankey MIT)
5. Render via SVG (acessivel)
6. Tooltip + highlight on hover
7. Color palette (Fluent2 default)
8. Click event handlers
9. 8 testes em `tests/.../SankeyTests.cs`
10. Criar `docs/components/sankey-diagram.md`
