# T130: XF3DCharts wrapper Three.js backend

## Objetivo
Implementar 3D charts (Surface, Bar3D, Scatter3D, Bubble3D) com Three.js backend. Syncfusion e o unico entre 8 fontes com 3D charts nativos.

## Passos
1. Adicionar Three.js 0.160+ ao `wwwroot/vendor/three/`
2. Criar `src/XForge.DesignSystem/Components/Charts/3D/`
3. Implementar `XF3DChart<TTool>` generic base

5. Camera controls (orbit, zoom, pan via OrbitControls)
6. Lighting (ambient + directional + point)
7. Materials (Phong, Standard, Physical)
