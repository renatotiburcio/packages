# T124: XFBlockEditor Notion-like block editor

## Objetivo
Implementar editor block-based tipo Notion com slash commands, drag-and-drop e serializacao JSON para CMS/docs/blog do XForge v2.0.0.

## Passos
1. Criar projeto `src/XForge.DesignSystem/Components/Editor/BlockEditor/`
2. Implementar `XFBlock.razor` + `XFBlock.razor.cs` com tipos Text, Heading, List, Quote, Code, Image
3. Implementar `XFBlockEditor.razor` + `.razor.cs` com state management + slash command palette
4. Implementar `XFBlockSerializer.cs` para JSON serialize/deserialize
5. Criar `IXFBlockStorage` interface para persistencia pluggable
6. Implementar `XFBlockStorage.InMemory` + `XFBlockStorage.LocalStorage` providers
7. Criar CSS tema XF: `wwwroot/xf-block-editor.css` (dark/light mode)
8. Criar `XForge.AssetsGenerator` rule para slash command icons (T080)
9. Adicionar 10 testes bUnit em `tests/.../BlockEditorTests.cs`
10. Criar demo `docs/components/block-editor.md` com exemplo completo
11. Criar sample app `apps/BlockEditorDemo` showcasing CMS use case
12. Adicionar WCAG 2.2 AA: keyboard nav, ARIA, screen reader
